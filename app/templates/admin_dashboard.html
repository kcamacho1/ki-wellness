💡 Token Limit Guidelines & What to Expect

Input Token Levels:

  • 300: Single meal entry + basic context
  • 500: 2-3 meals + mood + basic profile
  • 1000: Full day + detailed notes + profile
  • 1500: Multi-day context + detailed profile
  • 2000: Full week context + complete profile

Output Token Levels:

  • 300: Brief insights, key points only
  • 500: Concise analysis + 2-3 recommendations
  • 1000: Detailed analysis + 5-7 recommendations
  • 1500: Comprehensive insights + full guidance

Total Token Levels:

  • 600: Quick Q&A, minimal interaction
  • 1000: Basic analysis session
  • 2000: Standard coaching session
  • 3000: Enhanced coaching + follow-up
  • 3500: Full coaching experience

🎯 Cost Impact Examples:

• Lower limits (600-1000): ~$0.002-0.005 per request, great for high-volume users

• Current limits (3500): ~$0.008-0.015 per request, balanced quality & cost

• Higher limits (5000+): ~$0.015-0.025 per request, premium experience
