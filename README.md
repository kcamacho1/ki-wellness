# 🧘‍♀️ Ki Wellness – Holistic AI Health App

**Ki Wellness** is a full-stack wellness platform that combines AI, fitness, and nutrition to help users achieve mind-body-spirit balance.

[Click here to demo](https://ki-wellness.vercel.app)

---

## 🚀 Tech Stack

| Layer       | Tech                              |
|-------------|-----------------------------------|
| Frontend    | Next.js, Tailwind CSS             |
| Backend     | FastAPI (Python)                  |
| Database    | PostgreSQL (via Railway)          |
| AI Models   | PyTorch or Scikit-learn (via API) |
| Auth        | JWT-based (custom FastAPI logic)  |
| Hosting     | Vercel (Frontend), Railway (API/DB) |
| Payments    | Stripe                            |
| Video       | Zoom API                          |

---

## 📁 Folder Structure
/frontend # Next.js App (UI)
/backend # FastAPI App (APIs + ML)
/models # ML Models (.pt or .pkl)
/database # SQLAlchemy models, migrations

---

## 🧠 Features

- AI-generated meal suggestions
- Food Journal and logger
- Spiritual practice tracker
- Exercise Log
- Stripe checkout for 1-on-1 sessions
- Zoom integration for live calls
- Mood & health journal
- Dashboard with stats and progress
